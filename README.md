# Advanced Student Learning Analytics and Performance Dashboard

This repository contains an **Advanced Student Learning Analytics and Performance Dashboard** project developed using **Python** and **Microsoft Power BI**.  
The project focuses on analyzing student learning behavior, academic performance, and educational insights through interactive dashboards and data-driven visualizations.

## Project Overview

The main goal of this project is to convert student learning data into meaningful insights that can help understand performance trends, learning patterns, and academic outcomes.  
The dashboard provides a clear visual summary of student progress, performance indicators, and analytical findings for educational decision-making.

## Key Features

- Interactive Power BI dashboard for student performance analysis
- Python-based data processing and dashboard support
- Student learning behavior analysis
- Academic performance tracking
- Visual KPI cards for quick summary insights
- Data cleaning and transformation workflow
- Notebook-based analysis using Jupyter Notebook
- Clear charts and reports for educational analytics

## How to Use

1. Download or clone this repository.
2. Open the `student learning.pbix` file using **Microsoft Power BI Desktop**.
3. Open `update_enhanced_latest.ipynb` in **Jupyter Notebook** if you want to review or update the analysis.
4. Run `python_dashboard.py` if Python-based dashboard functionality is required.
5. Refresh the dataset in Power BI if needed.
6. Explore the dashboard visuals, filters, and insights.
